# Bahasa Umandana – Translator & Generator

Proyek ini adalah alat untuk menerjemahkan teks dari Bahasa Indonesia ke **Bahasa Umandana** dan sebaliknya.  
Bahasa Umandana adalah bahasa fiksi/kode unik yang dibuat untuk bersenang-senang, hiburan, atau kebutuhan komunitas.

## ✨ Fitur
- Translate Indonesia → Umandana  
- Translate Umandana → Indonesia  
- Generator kata Umandana  
- Ringan, cepat, berbasis web

## 🔗 Demo / Website
Kunjungi aplikasi online di sini:  
https://el48ai.github.io/umandana-translator/

## 📌 Cara Menggunakan
1. Masukkan teks yang ingin diterjemahkan  
2. Pilih arah terjemahan  
3. Klik tombol “Translate”  
4. Hasil akan muncul otomatis
